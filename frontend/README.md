# aep-frontend

React + TypeScript + MUI dashboard. One folder per screen under `src/features/*`
(see `docs/architecture/08-dashboard-ux.md`); `src/api-client/` is generated from the backend's
OpenAPI spec and must never be hand-written (`docs/architecture/02-repo-design.md` §4).

Currently a bare Vite scaffold — no screens are implemented yet.

## Dev

```
npm install
npm run dev
```
